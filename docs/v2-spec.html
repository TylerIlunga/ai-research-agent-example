01

What the audit found

Eight problems, found by reading the code rather than the README. Four of them mean a feature the interface advertises does not actually work.

Won't boot

The server exits on startup

Startup requires JWT_SECRET, MASTER_ENCRYPTION_KEY and KEY_DERIVATION_SALT, then calls process.exit(1). None of the three exist in .env. The uncommitted security work made local development impossible.

backend/src/index.ts:14–25
Silently dead

Citations never reach the UI

The browser calls JSON.parse on the search tool's output and looks for an array of {url, title}. The tool returns a formatted human-readable string. The parse always throws into an empty catch, so the Sources panel is permanently empty.

frontend/src/components/Chat.tsx:102–130 ↔ backend/src/tools/research.ts:86–103
Blocks streaming

gzip buffers the event stream

compression() is applied globally and has no filter exempting text/event-stream. Progress events sit in the compressor's buffer, so "real-time" arrives in bursts, or at the very end. There is no flushHeaders, no heartbeat, and no keep-alive against proxy timeouts.

backend/src/index.ts:37 · controllers/agentController.ts:181–208
Fragile

Sources are recovered by regex

The server rebuilds citations by running /URL: (https?:\/\/[^\s]+)/g over tool text and zipping the matches against a second regex for titles. Positional zipping across two independent match arrays mispairs whenever a title contains a hyphen.

backend/src/agents/researchAgent.ts:239–263
Leaks

No cancellation, ever

Closing the tab does not stop the run. The stream loop has no abort signal and no req.on("close") handler, so a cancelled research task keeps calling paid search and model APIs until it finishes talking to a socket nobody is reading.

backend/src/controllers/agentController.ts:195–208
Wrong output

Raw research is streamed as the answer

Every on_chat_model_stream token is appended to the visible message, including the tool-loop model's intermediate chatter. Then on_chat_model_end overwrites the whole message with the last output. The user watches text that is not the answer, then sees it replaced.

frontend/src/components/Chat.tsx:91–143
Design debt

Dark mode is declared but not built

globals.css sets dark background and foreground variables under prefers-color-scheme, while every component hard-codes bg-white, text-gray-800, border-gray-200. On a dark OS the result is dark chrome around white cards with unreadable contrast.

frontend/src/app/globals.css:16–21 vs. all components
Design debt

Emoji standing in for a design system

🔬 🔍 🧠 🤖 👤 carry the visual identity; three primary gradients compete for attention; the page title is still "Create Next App"; the three feature cards on the empty state are decorative, not clickable. There is no history, no stop, no retry, no export.

frontend/src/app/{layout,page}.tsx · components/*
02

The stance behind v2

Four commitments. Everything downstream is an application of one of them.

Today
  • The browser reverse-engineers LangGraph's internal event shapes.
  • The agent is one tool loop plus a "compress" step that dumps raw findings.
  • Missing keys are fatal; present keys are assumed to work.
  • Progress means three chips labelled with node names.
v2
  • The server owns a versioned event contract; the browser renders it.
  • Plan → research → synthesize, with sources as typed state, not text.
  • Every capability degrades on its own; the app boots with zero keys.
  • Progress means seeing the questions asked and the sources landing.

Why Claude Opus 5 changes the design, not just the string

Swapping the model name would be a one-line diff. The reason it is worth more is that Opus 5 makes a genuine planning step cheap enough to be worth having: it can decompose a question, run adaptive thinking between tool calls, and write a synthesis that stands on its own instead of a verbatim dump of everything found. The current compressResearch prompt explicitly instructs the model not to summarize — a workaround for a weaker model that now costs quality. v2 replaces it with a real synthesis node and moves effort control to output_config.effort, high for research, low for page summarization.

Two constraints come with it: sampling parameters are rejected on Opus 5, and Anthropic has no embeddings endpoint. So the model layer strips temperature before it reaches the wire, and OpenAI stays in the stack for one job only — vectors for Pinecone memory.

03

Backend: a graph with a shape

The graph moves from MessagesAnnotation — a bag of messages — to a typed state carrying the plan, accumulated sources, and per-step telemetry. Nodes emit protocol events directly rather than leaving the controller to infer meaning from framework internals.

planNode 1

One structured call, schema-constrained: restate the question, decide whether memory is worth consulting, and emit two to five concrete sub-questions with the searches that answer them. Cheap, and it gives the interface something to show within a second instead of a spinner.

emits status · plan
researchNode 2 · loops

The tool loop, bounded by a search budget rather than a raw message count: web_search, recall_memory, save_memory. The think_tool is deleted — adaptive thinking replaces a tool whose only effect was to burn a turn writing a reflection nobody reads.

The search tool returns { sources: Source[], digest: string }. Sources are appended to state by a reducer that dedupes on normalized URL, so citation numbering is assigned once, server-side, and never re-derived.

emits step · search · source · usage
synthesizeNode 3 · streams

The only node whose tokens reach the message body. Writes a structured brief — direct answer first, then evidence, then what remains uncertain — with inline [n] markers bound to the numbering already fixed in state.

emits token · report · done

Provider failover

The agent asks for a role, not a provider. Each role carries a fixed budget and effort, and a dispatcher picks the model behind it: Claude when a key is present, OpenAI when it is not. The graph, the tools, and the prompts are identical either way, so losing the Anthropic key costs quality rather than availability — and the interface says which model answered instead of leaving you to infer it from the output.

The failover speaks plain OpenAI-compatible HTTP, so it is not tied to a hosted vendor: pointing OPENAI_BASE_URL at Ollama, LM Studio, or vLLM makes a local model the fallback. Pinning MODEL_PROVIDER to a provider with no key is reported as a misconfiguration rather than silently resolving to the other one.

The third rung, and what it forced

The Claude Code CLI is the interesting one: it needs no API key because it borrows a login that already exists. Measurement is what made it usable rather than a novelty — three calls established that every invocation re-sends Claude Code's own tool definitions (~20–35K tokens) and pays ~5s of process startup, so a call costs about $0.15 no matter how short the prompt. Replacing its system prompt makes that worse, not better: it busts the cache and the tool schemas stay.

A dozen model calls per run at that price is not a failover, it is a bill. So the provider declares two traits — no tool calling, no bulk summarization — and the graph reads them. That produced direct research mode: search each planned sub-question yourself instead of asking a model to drive a tool loop. A run becomes exactly two model calls, and the same mode is what makes local models with weak tool support work at all. The capability limit turned into a feature that outlives it.

Keys from the interface

A settings panel documents both chains against live server state and accepts credentials at runtime, so the app can be made useful without editing a file and restarting. The guards are the interesting part: values are held in server memory only — never written to disk, never returned to the client, cleared on restart — and the endpoint is off outside development unless explicitly enabled. Anyone who can reach it could otherwise choose whose account the server spends from.

Configuration and degradation

A single zod-validated config module replaces the scattered process.env reads. In development, missing dev-only secrets are generated in memory with a warning rather than killing the process. Each external dependency becomes a capability flag: no Tavily disables search and says so; no Pinecone or OpenAI key disables memory and keeps research working; no Anthropic key returns a single actionable error instead of a stack trace. /healthz reports the resolved capability set, so the browser can show the truth in its status line.

Transport

Streaming moves from GET + EventSource to POST + fetch streaming: queries stop appearing in URLs and server logs, length limits disappear, and the client controls abort. Compression is given a filter that skips text/event-stream, headers are flushed immediately, a comment heartbeat goes out every fifteen seconds, and X-Accel-Buffering: no is set for proxies. req.on("close") aborts the graph.

04

The event contract

One versioned union type, exported from the backend and imported by the frontend. Adding a node no longer means teaching the browser a new LangGraph event shape.

EventPayloadWhat the interface does
status phase, label

Moves the trace to planning, researching, or writing.
plan questions[]

Renders the sub-questions as a checklist that ticks off as they resolve.
step id, kind, label, state

One row in the trace; transitions running → done → failed in place.
search id, query, resultCount

Shows the literal query issued — the single most useful debugging signal.
source n, url, title, domain, snippet

Appends a numbered source card the moment it is found.
token text

Appends to the answer. Only ever emitted by synthesize.
report markdown, sources[]

Authoritative final state; reconciles against the streamed text.
usage input, output, ms

Footer line: tokens and elapsed time per run.
error code, message, retryable

Inline message with a Retry button when retryable is true.
done reason

Closes the stream: completed, cancelled, or budget_exhausted.

The rule that keeps it honest: tokens are only emitted from the synthesis node. Everything the research loop says is a step, never message content. That single constraint removes the bug where the answer is written, replaced, and written again.

05

Frontend: a workspace, not a chat box

Research is not a chat. The output is a document with citations, produced by a process worth watching. The layout follows that: a persistent conversation rail, a reading column for the brief, and a live trace that collapses into a summary once the run finishes.

Design tokens

One token layer drives both themes — components never reference a raw color. The palette is drawn from research instruments rather than SaaS blue: a slate ground, ink text, a single indigo accent for interactive state, and semantic teal and amber reserved for source and warning states so accent and status never compete.

  • Decorative feature cards on the empty state.
  • "Create Next App" as the document title.
  • Client-side source parsing.
Added

Accessibility and behaviour

The answer region is an aria-live="polite" log, so streaming text is announced without flooding. Trace rows carry state in text and shape, not color alone. Every control is reachable by keyboard with a visible focus ring; Enter sends, Shift+Enter newlines, Esc stops a run. All motion is gated behind prefers-reduced-motion. Markdown gains GFM, so tables and strikethrough in the model's output render instead of leaking syntax.

08

Open items and assumptions

Neither hosted model key works right now — there is no ANTHROPIC_API_KEY, and the OPENAI_API_KEY returns "You have no credits remaining". That is what made the third rung worth building: the app now runs a complete research task on the Claude Code CLI with no key at all. What remains unverified is how Claude Opus 5 through the API answers, since the prompts are tuned for it.

Node 22. The 1.x LangChain docs state a Node 22 floor while the published engines say 18. An .nvmrc pins 22 rather than betting on which is right.

Brave and SearXNG are verified structurally, not live. Both reach their real endpoints and fail correctly; neither has been run with a working credential, so result quality through those backends is untested.

LangChain and sampling parameters. ChatAnthropic may send a default temperature, which Opus 5 rejects. The model factory verifies the outgoing parameters and, if the framework insists, subclasses it to strip them. Confirmed against the installed package, not assumed.

Embedding dimensions. The current code comments claim 1024 dimensions from text-embedding-ada-002, which produces 1536. The existing Pinecone index is therefore likely misconfigured. Memory becomes optional and the embedding model is configurable, so a dimension mismatch degrades memory instead of breaking research.

Left alone. Auth, rate limiting, key management, observability, and the load and security test suites stay as they are. They are not in the way once the server boots, and rewriting them is a separate piece of work.

Found during verification

Fixed

Every turn was recorded twice

The completed turn was committed to history from inside a React state updater. React double-invokes updaters in development, so each run appended two identical turns. The in-flight turn now lives in a ref and the commit happens outside the updater.

frontend/src/components/Chat.tsx — run()
Fixed

Hitting the tool ceiling would have 400'd

When the round-trip ceiling routes straight to synthesis, the transcript still ends in an assistant turn carrying an unexecuted tool_use block — which the API rejects for having no matching result. That trailing turn is now dropped.

backend/src/agents/researchAgent.ts — synthesize
Fixed

Citations rendered as plain text

The first citation pass emitted [[1]](cite:1). A bracketed link label parses as a nested reference, and react-markdown strips unknown URL schemes — so the markers never became links. They are now [1](#cite-1).

frontend/src/components/Brief.tsx
Fixed

Every POST run cancelled itself instantly

Cancellation listened on req's close. On a POST that fires when the request body finishes — a few milliseconds in — so every run aborted before it did any work. Invisible until a request got far enough to matter, because the earlier no-key runs failed first anyway. The listener belongs on res.

backend/src/controllers/agentController.ts
Fixed

A billing 429 took three minutes to surface

"No credits remaining" is a 429, and the SDK's default six retries with backoff turned a permanent failure into 179 seconds of silence — then reported it as "rate limiting, try again shortly". Retries are now capped, quota errors are classified as non-retryable, and the provider's own wording is passed through.

backend/src/models/*, agents/researchAgent.ts
Fixed

Token usage always read zero on the failover

Usage was read from Anthropic's response_metadata.usage; OpenAI reports tokenUsage with different field names. Both are normalized by LangChain into usage_metadata, which is now preferred, with the raw shapes as fallbacks.

backend/src/agents/runContext.ts
Fixed

Pinecone v8 changed the upsert signature

The stack migration surfaced it: v5 took upsert([records]), v8 takes upsert({records}). The @langchain/pinecone wrapper still pins the client to v5, so it was dropped and memory now talks to the v8 SDK directly — fewer dependencies, and no longer a major version behind.

backend/src/tools/memory.ts
Fixed

A second dev server made the app unreachable

CORS hardcoded ports 3000 and 3001, but another project on this machine already held IPv6 localhost:3000, so the frontend had to move — and was then blocked by its own backend. Development now trusts any loopback origin; production keeps the explicit allowlist.

backend/src/middleware/security.ts
Fixed

"Unavailable" was a lie when a provider was pinned

The settings panel marked every earlier option in a chain as unavailable. With MODEL_PROVIDER pinned they were never tried at all. The server now reports whether the choice was pinned, and the panel says "pinned" instead of implying the others failed.

config/env.ts · components/Settings.tsx
Fixed

Type-checking the tools exhausted the heap

LangChain's tool() generics expand recursively against a zod schema (TS2589), enough to OOM a whole-project tsc. A narrowed factory type keeps schema inference for the handler and stops the expansion.
